Core is the engine. Spak is the assembled car. core 是引擎，spak 是装配好交付的整车

Spak is a multi-file service project framework built on top of Koishi. It organizes plugin-based applications with structured support for configuration management, internationalization, CLI tooling, service orchestration, and an independent logging system. Spak 是一款基于 Koishi 的多文件服务项目框架。它以结构化的方式组织插件化应用，内置配置管理、国际化、CLI 工具链、服务编排与独立日志系统。

Built with TypeScript and a pnpm monorepo architecture — 8 hand-crafted core packages and 4 official plugins. Use just the engine via @spakjs/core, or import { createApp } from 'spak' for the whole car. 采用 TypeScript 编写，基于 pnpm monorepo 架构——8 个精心打造的核心包与 4 个官方插件。可以单独用 @spakjs/core 引擎，也可以直接 import { createApp } from 'spak' 一行起步。

Core Capabilities 核心能力

Built as a Framework 以框架为架构

Command & Middleware 命令与中间件

A typed Commander with parser and validator, plus a middleware processor for the full request pipeline. 带类型声明的 Commander（含 parser 与 validator），以及处理完整请求管道的中间件 Processor。

Multi-transport Logger 多通道日志

@spakjs/log ships Console/File/Stream transports with auto-rotating files and zero third-party deps. @spakjs/log 提供 Console/File/Stream 三个 transport，文件按大小自动轮转，零第三方依赖。

i18n & Config 国际化与配置

LocaleTree with fallback algorithm, YAML translation loader, T() helper, and a persistent ~/.spak/config.json store. LocaleTree 回退算法、YML 翻译加载器、T() 助手，以及持久化的 ~/.spak/config.json 用户级配置。
