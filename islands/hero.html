A Koishi-based Multi-file Service Framework 基于 Koishi 的多文件服务项目框架

MODULAR. TYPED. PLUGGABLE. 模块化。强类型。可插拔。

Spak is a multi-file service project framework built on top of Koishi. It structures plugin-based applications with built-in configuration management, i18n, CLI tooling, service orchestration, and an independent logging system. Spak 是一款基于 Koishi 的多文件服务项目框架。它以结构化的方式组织插件化应用，内置配置管理、国际化、CLI 工具链、服务编排与独立日志系统。
