What is Spak? Spak 是什么？

Spak is a multi-file service project framework built on top of Koishi. It provides a structured way to organize plugin-based applications with built-in support for configuration management, internationalization, CLI tooling, service orchestration, and an independent logging system. Spak 是一款基于 Koishi 的 多文件服务项目框架。它提供结构化的插件化应用组织方式，内置配置管理、国际化、CLI 工具链、服务编排与独立日志系统。

Spak uses TypeScript with a pnpm monorepo architecture, shipping with 8 hand-crafted core packages and 4 official plugins. Spak 采用 TypeScript 编写，基于 pnpm monorepo 架构，内置 8 个精心打造的核心包与 4 个官方插件。

The project is led by founder starlight-apk and maintained by the starpak team — a group of passionate developers committed to open source excellence. 项目由发起者 starlight-apk 主导，starpak team 维护——一支热爱技术、追求开源卓越的团队。
